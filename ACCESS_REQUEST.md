# Request research materials

Research code and fixed-model parameters for the AMI intestinal necrosis model are supplied in the encrypted archive `encrypted/AMI_code_model_v1.0.0_20261027.7z`. The password or decryption key is not stored in this repository.

## Contact

- Corresponding author: **Lie Yang**
- Email: **lie_222@163.com**

Do not include patient information, passwords or private keys in public issues or messages.

## Information to provide

1. Your name, institution and institutional contact details.
2. The purpose of access, such as methodological review, reproducibility assessment or independent research validation.
3. The requested release version and the researchers who would use it.
4. A brief description of the planned analysis and whether patient-level source data are also being requested.

Patient-data access is a separate request and is not included with access to code and model parameters. Do not attach patient datasets to the initial request.

## After review

The study team will determine whether access can be provided and specify the applicable written terms. Submitting a request does not guarantee approval; this document does not promise a review deadline or automatic delivery of credentials.

If access is approved, decryption credentials will be shared through a separately agreed channel. Verify the archive against the published SHA-256 checksum before extracting it, keep the credentials separate from the archive, and follow [TERMS_OF_ACCESS.md](TERMS_OF_ACCESS.md). The checksum verifies file integrity; it is not a password, encryption key or access authorization.
