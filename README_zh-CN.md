## 固定模型与既有结果

模型使用18项预编码变量，将10个XGBoost模型输出的概率取算术平均，估计本次住院期间确认的肠坏死概率。固定分界为**0.57**；按未四舍五入的概率判断，恰为0.57归入高风险组。

按研究团队确认的医院划分，中心1为开发集（**n=230**），中心2–3为外部验证集（**n=98**）。原研究汇总结果为：开发集10折OOF AUROC **0.827（95% CI 0.770–0.883）**；外部验证AUROC **0.826（95% CI 0.742–0.910）**。

临床输入映射已由研究团队于2026-10-26确认。
